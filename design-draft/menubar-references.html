01 / DISCOVERABILITY
Quiet when idle, explicit on focus
The menu bar keeps only the icon and status dot. The name appears while the popover is open so the user knows which utility has focus.

      
02 / HIERARCHY
One main action per moment
Save while working, review after saving, approve the draft, then copy or resume. Secondary controls stay visible but quiet.

      
03 / TRUST
Consent stays readable in a small space
Local save, model destination, blocked entries, exact payload, evidence links, and project drift have dedicated compact views.

    

    
Design reference only. Interactions use sample data; no files are read, commands run, or network requests sent.
